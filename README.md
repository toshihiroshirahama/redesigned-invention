# ギター・ベース・エフェクター・アンプ修理工房 ホームページ

集客を目的とした、楽器修理専門工房の1ページ完結型ホームページです。
HTML / CSS / JavaScript だけで動くので、どのレンタルサーバー・GitHub Pages・Netlify などにもそのまま置けます。

## 確認方法

`index.html` をブラウザで開くだけで表示できます。

## 他社サイトとの差別化ポイント

| 一般的な修理店サイト | このサイト |
| --- | --- |
| 料金は「要見積もり」で不明 | **料金シミュレーター**で症状を選ぶだけで料金・期間の目安を即表示 |
| 専門用語のメニュー一覧 | **「症状から探す」**：「音が出ない」「ガリ」など、お客様の言葉で探せる |
| 何をしたか分からない | **作業写真・測定値つき修理レポート**を約束（見本を掲載） |
| 追加料金が不安 | **作業前に料金確定・追加請求なし**を明記 |
| 修理後の扱いが不明 | **修理後保証**を明記 |
| 来店前提 | **店頭 / 全国宅配**の2つの流れを切り替えて案内 |
| PC向けの古いデザイン | スマホ最優先。画面下に常に「料金を調べる / LINE / 見積もり」ボタン |
| 検索に弱い | 店舗情報・FAQの構造化データでGoogle検索・マップに強い |

シミュレーターの「この内容で無料見積もりを依頼」を押すと、選んだ内容が問い合わせフォームに自動で入ります。

## 公開前に必ず書き換える箇所

`【 】` で囲まれた部分はすべて仮の文字です。`【` で検索して置き換えてください。

- **index.html**: 店名、電話番号、住所、営業時間、LINEのURL、保証期間、診断料、職人のプロフィール、構造化データ（`<head>` 内）
- **修理事例**: 掲載例なので、実際の事例と写真に差し替えてください（写真が集客に最も効きます）
- **Googleマップ**: 「工房案内」の `.map` 内を、Googleマップの埋め込み iframe に置き換え
- **料金**: `assets/main.js` 冒頭の `MENU`（シミュレーター・症状）と、`index.html` の料金表を実際の料金に
- **問い合わせフォーム**: `assets/main.js` の `CONFIG.email` を実際のメールアドレスに。
  [Formspree](https://formspree.io/) などのURLを `CONFIG.formEndpoint` に入れると、メールソフトを使わず直接送信できます

## 集客をさらに伸ばすために

1. **Googleビジネスプロフィール**を登録し、このサイトのURLを設定（地域検索で最重要）
2. 修理事例を**毎月追加**（ビフォー/アフター写真＋料金＋期間）
3. お客様の口コミは実際にいただいたものだけを、許可を得て掲載
4. LINE公式アカウントで写真見積もりを受付
